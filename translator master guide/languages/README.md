# Language worksheets

Work in your language folder. Leave the root `units/` folder unchanged. That folder is the shared English source, and its `translation` field stays empty.

`spanish` and `chinese` on every row are the official references. They show meaning and tone. The field you write is `translation`.

## Where to work

- `languages/zh/`: 简体中文. `translation` already holds the current official Chinese. Revise it.
- `languages/ru/`: Русский. `translation` is empty.
- `languages/de/`: Deutsch. `translation` is empty.
- `languages/it/`: Italiano. `translation` is empty.
- `languages/ko/`: 한국어. `translation` is empty.
- `languages/ja/`: 日本語. `translation` is empty.
- `languages/pl/`: Polski. `translation` is empty.
- `languages/ar/`: العربية. `translation` is empty.

Read `00_INSTRUCTIONS.md`, `01_STYLE.md`, `02_GLOSSARY.md`, and `03_OFFICIAL_CHOICES.md` in the parent folder before the first line. Then read the README inside your language folder.
